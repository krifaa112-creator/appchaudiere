# Bibliothèque de pièces chaudières

Application locale pour rechercher des modèles de chaudières et leurs numéros de pièces.

## Utilisation simple

Ouvrez `index.html` dans Safari, Chrome, Edge ou Firefox.

Les données sont enregistrées dans le navigateur utilisé. Pour sauvegarder ou déplacer vos données vers un autre appareil, utilisez **Exporter JSON**, puis **Importer JSON** sur l'autre appareil.

## Installation comme application

### macOS et Windows

1. Mettez le dossier de l'application en ligne ou lancez-le sur un petit serveur local.
2. Ouvrez l'application dans Chrome, Edge ou Safari.
3. Utilisez l'option du navigateur pour installer l'application.

### iPhone et iPad

1. Ouvrez l'application avec Safari.
2. Touchez **Partager**.
3. Touchez **Ajouter à l'écran d'accueil**.

Important : iOS ne permet pas d'installer directement un fichier `.zip`, `.exe` ou `.dmg`. Pour iPhone/iPad, la bonne solution est l'installation depuis Safari comme application web.

## Fichiers inclus

- `index.html` : interface de l'application
- `styles.css` : design
- `app.js` : logique et stockage
- `manifest.webmanifest` : informations d'installation
- `service-worker.js` : cache hors ligne quand l'application est servie en HTTP/HTTPS
- `icon.svg` : icône de l'application
